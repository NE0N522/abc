# Публикация на GitHub Pages

## Перед включением Pages

Убедись, что в корне репозитория `NE0N522/abc` находятся:

- `index.html`
- `styles.css`, `app.js`, `bootstrap.js`
- `manifest.webmanifest`, `service-worker.js`
- папка `data` с файлами словаря и иконками

`index.html` должен быть непосредственно в корне ветки `main`. Не загружай только `offline.html`: раздельная PWA-версия использует JSON из папки `data`.

## Настройка

1. Открой [репозиторий](https://github.com/NE0N522/abc).
2. Нажми **Settings**. Если вкладка скрыта, открой меню **More** и выбери **Settings**.
3. В боковом меню открой **Pages**.
4. В блоке **Build and deployment** установи **Source** → **Deploy from a branch**.
5. В **Branch** выбери `main`, а в папке — `/(root)`.
6. Нажми **Save**.

GitHub Pages публикует выбранную ветку и папку; для этой сборки это `main` и корень репозитория. [Официальная инструкция GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Проверка

1. Дождись, пока GitHub завершит workflow публикации. Его состояние видно во вкладке **Actions** или в разделе **Pages** в настройках.
2. Открой `https://ne0n522.github.io/abc/`. Для проектного сайта адрес формируется как `https://<владелец>.github.io/<имя-репозитория>/`. [Как устроены сайты GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages).
3. Проверь поиск, переключение уровней и загрузку карточек A1–B2. Если словарь не загружается, проверь, что каталог `data` находится в корне рядом с `index.html`, и что имена файлов не изменились.
4. После первого открытия с интернетом проверь офлайн-режим: дай странице завершить загрузку, закрой вкладку, отключи интернет и снова открой опубликованный адрес.
5. Чтобы установить PWA, открой сайт в браузере телефона и выбери установку приложения (Android) или добавление на главный экран (iPhone).

Автоматический перевод непроверенных карточек требует интернет. Прогресс хранится в браузерном хранилище устройства и не синхронизируется между разными устройствами автоматически.
