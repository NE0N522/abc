# Приёмка и ограничения

## Совместимость, которую сохраняем

- ID всех 3 310 слов, формат `data/*.json`, `data/storage-core.js`, существующие ключи IndexedDB/localStorage и формат экспорта/импорта не менялись.
- Статусы и интервалы повторения сохранены: «Знаю» выставляет статус 2, «Повторить» — статус 1. В диктанте правильный ответ по-прежнему ставит статус 2, неправильный — статус 1; пропуск также считается требующим повторения.
- Выбор голоса действует до перезагрузки страницы и не записывается в IndexedDB/localStorage, поэтому существующие ключи и форматы не меняются.
- Внешние шрифты и наборы иконок не добавлены. SVG-кнопки встроены в интерфейс, PWA-иконки хранятся локально.

## Изменения интерфейса

- Упрощена шапка: бренд, один поиск, серия занятий и настройки.
- Главная показывает текущую цель, сводку прогресса, уровни, этапы и слова в отдельной иерархии.
- Мобильная версия получила нижнюю навигацию, закреплённую кнопку занятия и safe-area отступы.
- Стили собраны в токены, светлая и тёмная темы имеют отдельные поверхности и цвета текста; системный стек шрифтов заменил не подключённый Inter.
- Эмодзи заменены inline-SVG, фильтры имеют состояние выбранности, массовая отметка этапа находится в дополнительном меню и сохраняет подтверждение, копию и отмену.
- Поиск общий для обучения и словаря. Поиск и словарь показывают до 50 слов на странице, чтобы не отрисовывать тысячи строк одновременно.
- Карточки запускаются на 10, 20 или 40 слов, переворачиваются, показывают прогресс и позволяют повторить ошибки. Клавиши: `←`/`1` — повторить, `2`/`Space` — показать перевод, `→`/`3` — знаю, `S` — произнести.
- В диктанте добавлена проверка альтернатив написания, посимвольная подсветка ответа и переход клавишей `Enter`.
- В настройках можно выбрать светлую, тёмную или системную тему, изменить размер текста, включить медленную речь и выбрать установленный английский голос.
- Автопереводы помечаются бейджем. Без Web Speech API звуковые кнопки открывают Oxford Dictionary для слова или YouGlish для примера.

## Проверки

- `node tools/build-offline.js` создал актуальный `offline.html`; три встроенных блока скриптов прошли `vm.Script` проверку синтаксиса.
- `node --check` прошёл для `app.js`, `bootstrap.js`, `service-worker.js` и `tools/build-offline.js`.
- JSON манифеста, legacy-карты и четырёх уровней разбирается; уровни содержат 902 / 872 / 809 / 727 записей, всего 3 310. Legacy-карта содержит 3 310 уникальных соответствий.
- Восемь имеющихся проверок хранилища прошли. Они используют тот же файл `storage-core.js` (проверена идентичность SHA-256) и те же 3 310 соответствий legacy-карты.
- Локальный HTTP-сервер вернул `200` для `index.html`.
- Палитра основных пар текста и кнопок проверена расчётом: контраст выше 4.5:1 в светлой и тёмной темах.
- Полную визуальную проверку в браузере выполнить не удалось: инструмент управления Windows отклонил локальный URL из-за отсутствия поддержки URL-политики. Поэтому экраны 360 / 390 / 768 / 1280 px, системный режим тёмной темы, установку PWA и фактическую офлайн-навигацию нужно проверить в браузере вручную.
- Экспорт/импорт и сохранение прогресса проверены на уровне существующего модуля хранилища; полный сквозной UI-сценарий и стресс-тест 3 310 отметок в браузере не запускались.

Содержательная редакторская проверка слов остаётся отдельной задачей: готово 75 из 3 310 карточек; список для вычитки находится в `translation-review.md`.

## Ограничения

- Автоперевод требует интернета и не считается вычитанным человеком. Он кэшируется отдельно от прогресса.
- Прогресс не синхронизируется автоматически между разными устройствами; для переноса используй экспорт и импорт.
- Голос доступен только если браузер предоставляет английские голоса. Если нет, открывается Oxford Dictionary или YouGlish.
- Проверка интерфейса в настоящем браузере не заменяет отдельный стресс-тест всех 3 310 отметок и проверку IndexedDB между несколькими вкладками.
- Набор слов не сверялся построчно с официальным списком Oxford.
