# Приёмка и ограничения

## Что реализовано

- Сохранён исходник без изменений: bossabc.legacy.html; рабочая копия: bossabc.html. Таблица legacy-map.json содержит 3,310 соответствий старых индексов стабильным ID.
- Прогресс мигрирует на схему версии 2. Используются IndexedDB с запасным localStorage, отложенная запись и синхронизация вкладок с объединением по времени каждой записи. Добавлены резервные копии, импорт/экспорт, подтверждение сброса и отмена последней массовой операции.
- Восстановлен автоматический перевод CSV как fallback для непроверенных записей. Переводы кэшируются отдельно от прогресса; проверенные вручную карточки показываются в первую очередь. Ссылки на Oxford, YouGlish и Tatoeba остаются переходами по нажатию.
- Данные разнесены по data/A1.js–data/B2.js; A1 отображается сразу, остальные уровни подгружаются по требованию. Добавлены поиск по значениям и карточка слова.
- Исправлена разметка карточек: кнопка слова получила явный layout, прозрачный фон и контрастные цвета из темы; переводы и сами заголовки теперь отображаются отдельными строками.
- Если Web Speech API недоступен, кнопки звука открывают Oxford Dictionary для слова и YouGlish для примера. Пример при озвучивании сохраняет запятые.
- Авторская разметка готова для A1 · этапы 1–3: 75 записей. Всего в данных с проверенными значениями 75 записей.

## Проверки

- Legacy ID map covers 3,310 unique stable IDs; migration keeps all 3,310 statuses and user sentences.
- Corrupt JSON parsing preserves the raw damaged value for quarantine; backup state can be normalized.
- Per-word timestamp merge preserves concurrent edits to different words.
- Import accepts old exports and valid checksummed exports; checksum tampering is rejected.
- Quota errors fall back to localStorage; failed writes leave the in-memory state unchanged.
- Reset undo state restores statuses and user sentences.
- Application VM smoke boot renders a reviewed A1 card and handles the automatic translation fallback while offline.
- Automatic CSV fallback fills an unreviewed word; verified manual entries remain the displayed source.
- When Web Speech API is unavailable, word/example audio controls open Oxford/YouGlish pronunciation pages.
- Application migration smoke test writes all 3,310 old progress marks under stable IDs.

- Автоматически проверены батчи A1:1–3 отдельными запусками валидатора.
- Полная проверка содержания закономерно не проходит: остаются 3235 записей без проверенных значений.
- Искусственный тест демонстрирует риск «последний снимок целиком победил» в старом формате. Исходную потерю пользователя нельзя подтвердить по сохранённому состоянию браузера; конкретная историческая причина неизвестна.
- Скриншоты и Lighthouse не получены: браузер отказал в открытии локального file:// предпросмотра, а политика сессии запретила обход через локальный сервер или другой браузер.

- Коммиты не созданы: рабочая папка не находится внутри Git-репозитория.

## Не завершено

- Переводы и редакторская вычитка оставшихся 3235 слов (см. translation-review.md). Из прежних 125 переводов 75 попали в сверенный этап; ещё 50 остаются переходными без отдельной ревизии.
- В интерфейсе есть база для обучения, режима «Сегодня», словаря, карточек, диктанта, настроек и восстановления, но не все пункты спецификации доведены до готового состояния. В частности, карточки не предлагают сеансы 10/20/40 и горячие клавиши ←/→/1/2/3/пробел/S; диктант пока не принимает список альтернатив написания и обновляет статус по старой логике «верно → знаю»; голос не выбирается.
- Не подтверждены визуальная адаптивность в реальном браузере, офлайн PWA, полноценный сценарий IndexedDB в нескольких вкладках и фактический стресс-тест 3,310 кликов в UI.
- Список и уровни слов по официальному Oxford не сверялись построчно. Официальное описание Oxford подтверждает состав Oxford 3000 и выравнивание A1–B2, но это не доказывает тождество данного набора записей.
