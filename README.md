# Oxford 3000 English Trainer

## Быстрый запуск

- Для обычного запуска дважды щёлкни по offline.html. Это автономная копия со всеми уровнями внутри.
- Для раздельной версии с HTML/CSS/JS/JSON запусти start.bat и открой страницу, которую запустит браузер. JSON-файлы загружаются по локальному HTTP; браузеры обычно блокируют их при открытии index.html напрямую через file://.
- Чтобы пересобрать offline.html после изменений в исходных файлах, выполни в этой папке: node tools/build-offline.js.

## Установка на телефон как приложение (PWA)

- Сначала размести содержимое этой папки на статическом хостинге с HTTPS. Открытие offline.html двойным щелчком подходит для компьютера, но не даёт установить PWA.
- Открой опубликованный адрес на телефоне и выбери установку: в Chrome на Android — «Установить приложение»; на iPhone — «Поделиться» → «На экран Домой».
- После первой загрузки основные уровни и функции работают офлайн. Автоматический перевод для непроверенных карточек загружается из интернета.
- Для установки PWA нужен именно index.html; он уже указан в manifest.webmanifest и закэширован service-worker.js.

## Структура

- index.html — разметка.
- styles.css — стили.
- app.js — логика приложения.
- data/A1.json … data/B2.json — словарь по уровням.
- data/legacy-map.json — соответствие прежних ID стабильным ID.
- data/storage-core.js — миграция и сохранение прогресса.
- offline.html — автономная сборка для двойного щелчка.

Прогресс хранится в IndexedDB браузера с резервом в localStorage; JSON словаря не перезаписывается отметками пользователя. Для переноса прогресса между старой версией и этой сначала экспортируй резервную копию в старой версии, затем импортируй её в новой.

Автоматические переводы для непроверенных карточек загружаются из исходного CSV при наличии интернета и кэшируются отдельно. Вручную подготовленные карточки имеют приоритет. Сейчас вручную проверены 75 карточек; список остальных находится в docs/translation-review.md.

## Зависимости

Запуск index.html через start.bat требует Python 3. Автоперевод использует интернет; базовый словарь, приложение и offline.html находятся в этой папке. Файлы PWA готовы, но сайт ещё нужно загрузить на HTTPS-хостинг.
