# Oxford 3000 English Trainer

Тренажёр английских слов для русскоязычных: 3 310 записей уровней A1–B2, повторение, карточки, диктант и словарь.

## Быстрый запуск

- Открой `offline.html` двойным щелчком, чтобы пользоваться автономной сборкой на компьютере.
- Для раздельных файлов запусти `start.bat`. Он поднимет локальный HTTP-сервер; открывать `index.html` напрямую через `file://` не нужно, потому что браузер блокирует загрузку JSON.
- После изменений выполни `node tools/build-offline.js`, чтобы пересобрать автономную страницу.

## Обучение

- Главная кнопка продолжает текущий уровень и этап. Для занятия карточками можно выбрать 10, 20 или 40 слов; в конце доступно повторение ошибок.
- В карточках работают клавиши: `←` или `1` — повторить, `2` или `Space` — показать/скрыть перевод, `→` или `3` — знаю, `S` — произнести слово.
- Диктант принимает альтернативные написания из словаря, показывает различия в ответе и проверяет ответ клавишей `Enter`.
- Поиск один для обучения и словаря. Результаты большого поиска и страницы словаря разбиты на страницы.
- Автоматические переводы помечены бейджем «Автоперевод». Они загружаются из исходного CSV при наличии интернета; вручную подготовленные переводы имеют приоритет.
- Тема, размер текста и выбранный английский голос настраиваются через меню «Настройки». Если Web Speech API или английские голоса недоступны, кнопки звука открывают Oxford Dictionary.

## Прогресс и данные

Прогресс хранится в IndexedDB с резервом в localStorage. ID слов, формат словаря, схема прогресса и экспорт/импорт сохранены для совместимости с предыдущими версиями. Выбор голоса хранится отдельно и не меняет файл прогресса. Резервные копии и перенос прогресса находятся в «Настройки и данные».

## PWA и GitHub Pages

Размести содержимое корня репозитория на HTTPS. Для установки на Android открой сайт в Chrome и выбери «Установить приложение»; на iPhone — «Поделиться» → «На экран Домой». Первый запуск требует сети, после него основные файлы и данные словаря кэшируются для работы без подключения. Автоперевод требует интернета.

Подробные шаги для GitHub Pages находятся в [`docs/github-pages.md`](docs/github-pages.md). В настройках Pages выбери ветку `main` и каталог `/(root)`.

## Файлы

- `index.html` — разметка приложения.
- `styles.css` — дизайн-токены, темы и адаптивные стили.
- `app.js` — обучение, словарь и работа с прогрессом.
- `bootstrap.js` — загрузка данных и запуск приложения.
- `data/A1.json` … `data/B2.json` — слова и учебные примеры.
- `data/legacy-map.json` и `data/storage-core.js` — стабильные ID и совместимое хранилище прогресса.
- `offline.html` — автономная сборка для запуска без сервера.
- `service-worker.js` и `manifest.webmanifest` — офлайн-кэш и установка PWA.

Все шрифты системные, иконки приложения локальные или встроенные SVG; внешние шрифты и CDN не используются. Сейчас отдельно вычитаны 75 учебных записей; редакторская проверка оставшихся переводов описана в [`docs/translation-review.md`](docs/translation-review.md).
